# Shopease E-commerce Project

## About
Shopease is an e-commerce project developed for TY BSc CS.
It is designed to provide an online shopping platform where users can browse products, view product details, and explore a smooth shopping experience.

## Features
- Browse products
- Search products
- View product details
- User-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript
